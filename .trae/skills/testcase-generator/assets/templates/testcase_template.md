## 用例类型说明

| 类型 | 说明 |
|------|------|
| 功能测试 | 核心业务主流程、正常场景验证 |
| 边界测试 | 输入数值边界、数量上限、状态临界条件 |
| 异常测试 | 非法输入、错误操作、异常业务分支处理 |
| 权限测试 | 未登录访问、越权操作、多角色权限校验 |
| 并发测试 | 重复提交、多端并发、数据竞争 |

## 优先级定义

| 优先级 | 占比 | 定义 |
|-------|------|------|
| P0 | 10-25% | 核心功能、主干业务流程，必测不可缺失 |
| P1 | 30-60% | 重要功能、主流用户常用场景 |
| P2 | 10-25% | 边缘功能、特殊小众场景、兼容兜底场景 |
